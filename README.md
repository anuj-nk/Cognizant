# Python Capstone: Personal Finance Tracker

This is a simple command-line personal finance tracker built in Python. It allows users to:

- Add and categorize expenses
- View all recorded expenses
- Get a summary of total spending by category
- Handle invalid input 

## How to Run

1. Clone the repository:
    git clone https://github.com/anuj-nk/Cognizant/tree/python-capstone-finance-tracker
    
    cd python-capstone-finance-tracker

2. Run the script:
    python finance_tracker.py

## Python Concepts Used

- Variables and data types
- Lists, dictionaries, and tuples
- Functions
- Loops and conditionals
- Exception handling (`try`, `except`)
- User input and string operations
